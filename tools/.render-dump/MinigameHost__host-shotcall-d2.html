🗣Objective Timers

Macro is not a feeling, it is a checklist read out loud before anyone has time to think. This drill throws compact game states at you on a clock - gold, objective timers, death timers, summoners, wave states - and asks for the call. Every scenario has a best call and a runner-up that is nearly as good, plus one option that is greedy and one that is simply bait. Reading the state is half of it; saying it before the window closes is the other half.

Run the whole mid game from a spreadsheet of spawn timers you are not allowed to look at.

1Read the state chips, then pick one of four calls.
2Keys 1 - 4 or click. Answering early is worth a small bonus.
3Letting the timer run out scores zero. Guessing beats silence.
4The reveal names the right call and the runner-up. Space skips it.
